Place tor.exe and its DLLs here (from the Tor Expert Bundle).

Download: https://www.torproject.org/download/tor/

Extract the bundle and copy these files into this folder:
  tor.exe
  tor-gencert.exe (optional)
  Any .dll files included with the bundle

The browser will auto-start Tor from here on launch.
If this folder is empty, the browser will try system Tor (PATH) instead.
